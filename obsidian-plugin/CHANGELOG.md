# LocalOCR Sync 更新紀錄

每個版本由 CI 發佈為 GitHub Release「obsidian-plugin-<版本>」，再由 LocalOCR 伺服器同步到 Railway 儲存空間；插件從這裡讀取更新內容（`## <版本>` 下的文字）。

## 1.5.1

- 這台裝置改的筆記更快通知 iPad：最後一次修改 4 秒後（原本 8 秒）；Remotely Save 還在上傳時等它傳完才通知，iPad 一收到就拿得到新版本

## 1.5.0

- 即時同步改由伺服器即時推送（WebSocket）：iPad 或其他裝置修改筆記時伺服器立即通知，不必再每 25 秒詢問一次；連線中斷時依 1、2、5、15、60 秒自動重新連線，並補上斷線期間的修改。伺服器是舊版或網路不允許 WebSocket 時自動改用原本的輪詢方式（之後每 10 分鐘再嘗試一次即時推送）。設定頁的狀態會顯示目前是「即時推送」或「輪詢」
- 這台裝置修改的筆記改經由同一條連線通知其他裝置（未連線時仍用 HTTP）
- 「設定 Remotely Save」的自動同步改回每 5 分鐘一次：修改已由即時同步立即觸發，定時同步只是備援（需要更新後的 LocalOCR 伺服器；已設定過的裝置可在「設定 Remotely Save」重新套用）

## 1.4.0

- 即時同步：iPad 或其他裝置修改筆記後，幾秒內自動執行 Remotely Save 同步，不必再等定時同步；在這台裝置修改的筆記上傳後，也會通知 iPad 與其他裝置。可在插件設定「裝置設定 → 即時同步」關閉，並查看連線狀態（需要更新後的 LocalOCR 伺服器）
- 「設定 Remotely Save」的自動同步改為每分鐘一次（原本每 5 分鐘）：已設定過的裝置需在「設定 Remotely Save」重新按一次「套用到這台裝置」並重新啟動 Obsidian 才會生效

## 1.3.1

- 修正 Windows／Mac 版「套用到這台裝置」一定失敗的問題：桌面版 Obsidian 透過作業系統開啟連結時會拿掉保險庫名稱，Remotely Save 因此拒絕匯入；現在直接呼叫 Remotely Save 的匯入功能，各平台都能套用
- 新增「複製設定連結」：萬一套用沒有反應，可以貼到 Remotely Save 設定頁的匯入欄位

## 1.3.0

- 線上更新改由你的 Railway 伺服器提供：伺服器把每個新版本存進自己的儲存空間，插件先讀取 `<伺服器網址>/obsidian-plugin/latest.json`，下載後逐一比對 SHA-256
- 未填伺服器網址、伺服器還沒有可用版本或連不上時，自動改從 GitHub 更新
- 第一次手動安裝可以直接從伺服器下載 `main.js` 與 `manifest.json`

## 1.2.0

- 線上更新：啟動 Obsidian 時（之後每 6 小時）檢查新版本，自動下載、驗證並安裝，不必再手動複製檔案
- 新指令「檢查並更新插件」；插件設定新增「更新」區塊（目前版本、檢查並更新、自動更新開關）

## 1.1.1

- 配對時不再指定「iPad 筆記」資料夾：App 同步整個保險庫，筆記可以放在任何資料夾

## 1.1.0

- 「配對 iPhone／iPad」（QR Code 與配對碼）與「設定 Remotely Save（同步 vault）」

## 1.0.0

- 把 LocalOCR 伺服器的掃描同步成 Markdown 筆記與 JSON 陣列
